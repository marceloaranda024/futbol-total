# Fútbol Total

## Descripción
Fútbol Total es un proyecto web dedicado al mundo del fútbol. Presenta información sobre equipos, jugadores y competiciones para los aficionados a este deporte.

## Objetivo
Crear un espacio digital informativo que permita conocer más sobre el fútbol y sus principales protagonistas.

Marcelo Aranda

## Estado actual del proyecto
En desarrollo. Se está creando la estructura inicial de la página y ampliando su contenido.
